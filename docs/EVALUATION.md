# Evaluation preregistration — original baseline

> Historical protocol registered before the initial detector evaluation. For the current V8 protocol, see [V8_EVALUATION_PROTOCOL.md](V8_EVALUATION_PROTOCOL.md); for subsequent measured host and physical-device results, see [PROJECT_STATUS.md](../PROJECT_STATUS.md) and [Pi 5 status](../results/pi5/STATUS.json). Pending states in this historical protocol refer to the original registration date, not current submission status.

Protocol registered 2026-11-16 before training and before final heldout execution.

1. UCI labels are spam/ham, not adjudicated scam/safe. Treat the score as a spam proxy. The UI bands are selective decisions from a binary detector.
2. Normalize inputs with the production input boundary. Group exact normalized duplicates and character n-gram cosine neighbors >=0.90, including transitive components. URLs and digits are canonicalized for grouping only. Grouping uses text, never target outcomes. Group formation sees all texts only to prevent leakage; no classifier TF-IDF or learned prediction features see heldout texts.
3. Seed 20261115. Ten stratified group folds: 0-1 test, 2-3 validation, 4 calibration, 5-9 training. Groups do not cross partitions. This approximate 50/10/20/20 split is deliberately conservative; class balance is approximate under grouping.
4. Fit word TF-IDF (unigrams/bigrams, sublinear TF, min_df=2, max_features=20000) and balanced logistic regression (C=1, liblinear, max_iter=1000) on training only. No synthetic examples are used to fit this baseline.
5. Fit a sigmoid on calibration logits only. Retain it only if validation Brier AND log loss improve and its slope is positive. Brier includes discrimination and does not prove perfect calibration. No isotonic fitting or hyperparameter search.
6. Select two thresholds on validation only. Search low 0.05..0.475 and high 0.50..0.975 in 0.025 increments. Maximize coverage with observed ham false-positive rate <=1% and spam assigned LEGITIMATE <=5%; ties favor fewer false positives then misses. If no feasible pair, use [0,1] and report the unmet criterion. These observed constraints do not guarantee heldout or deployment rates.
7. Synthetic Indian/Hinglish challenge cases are AI-assisted project-written fictional examples, not a real-world sample or independent human annotation. Family-exclusive development and heldout partitions are predefined. Ambiguous examples have null labels, are excluded from supervised metrics, and retained for qualitative review. No threshold/model tuning on this challenge set.
8. Freeze model checksum and code before one final evaluation. The evaluation script requires a freeze JSON with model_sha256 and refuses to overwrite final results. If bugs require an evaluation change afterward, record an amendment and call subsequent results exploratory, not untouched holdout.
9. Report source datasets separately: precision, recall and F1 for SCAM vs all other bands (thus abstained positives count as missed for recall), false-positive rate over all ground-truth negatives, separately missed-positive LEGITIMATE fraction, abstention, coverage, and a 2x3 ground-truth-by-decision confusion matrix. A 3x3 matrix would falsely invent uncertain ground truth. Also report binary score>=0.5 confusion and Brier. Include Hinglish and legitimate synthetic subsets and sample counts. No real-world Indian accuracy claim.
10. Validator and fallback rates need actual model outputs; scripted malformed outputs are security tests, not Llama behavior measurements. Llama/template 20-case comparison and five-person clarity study remain BLOCKED/PENDING until model/participants exist. Host latency is reported separately; all Pi timings remain PENDING_HARDWARE.

Limitations: near-duplicate detection is heuristic and cannot prove semantic independence. Repeated source messages within a heldout group remain correlated and can over-weight template families. No confidence intervals treating rows as independent are claimed. UCI domain/time shift, class weighting and synthetic selection limit generalization.
