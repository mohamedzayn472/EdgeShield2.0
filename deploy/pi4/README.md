# Pi4 deployment

Start with `bash deploy/pi4/setup.sh` from the transferred bundle root on the target.
Read [the complete deployment procedure](../../docs/PI4_DEPLOYMENT.md) first for OS provisioning and missing licensed model assets.

No Pi hardware has been tested. The example manifest is intentionally unusable until genuine artifacts are acquired/exported/built and hashed. Setup installs only from the bundled target wheelhouse; launch requires a real manifest and loader checks. Offline verification and benchmarks write real logs only when executed on the device.
